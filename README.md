# 🐍 Python in 30 Days

> A structured 30-day journey to build a strong foundation in Python through theory, practice, and progressively more complex projects.

This repository documents my progress learning Python from the fundamentals to more advanced programming concepts. Each day focuses on a specific topic, combining explanations with practical examples and exercises.

The goal is not only to learn Python syntax, but to develop **problem-solving skills and programming habits** that can later be applied to engineering, simulation, and aerospace projects.

## 🚀 Projects

Mini-projects are developed throughout the course to apply the concepts learned during the previous lessons.

### Project 01 — Rocket Mission Control

A small Python program that applies fundamental concepts such as:

* User input
* Variables and data types
* Arithmetic operations
* Formatted output
* Basic calculations

The project simulates a simple **rocket mission report**, calculating parameters such as dry mass and fuel percentage from user-provided mission data.
