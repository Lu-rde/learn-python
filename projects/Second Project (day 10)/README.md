# 🪨 Rock Paper Scissors

> A beginner Python project that recreates the classic Rock Paper Scissors game using fundamental programming concepts.

## 📌 Overview

**Rock Paper Scissors** is the second mini-project developed during my **Python in 30 Days** journey, following the first six days of learning and continuing the application of concepts introduced throughout the following days.

The program allows the user to play Rock Paper Scissors against the computer, randomly generates the computer's choice, determines the winner, and keeps track of the **rounds played and the user's points**.

## ⚙️ How It Works

The program asks the user to choose between:

* 🪨 Rock

* 📄 Paper

* ✂️ Scissors

The computer then randomly selects one of the three options.

The program compares both choices and determines whether:

```text
YOU WIN!

YOU LOSE!

DRAW!
```

After each round, the game updates the number of rounds played and the user's score.

At the end of the game, the program displays:

```text
ROUNDS PLAYED: X
YOUR POINTS: X
```

---

## 💻 Example

```text
Choose Rock, Paper or Scissors: rock

Computer chose: scissors

YOU WIN!

ROUNDS PLAYED: 1
YOUR POINTS: 1
```

After playing multiple rounds:

```text
ROUNDS PLAYED: 5
YOUR POINTS: 3
```

## 🎯 Purpose

The purpose of this project was to practice **random number generation, loops, conditionals, user input, and counters** by turning them into a simple interactive game.

It is an exercise in combining several basic Python concepts into a program that can make decisions and respond to user input.
